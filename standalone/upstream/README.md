# PC/US data recipes

The source export is pinned in source.sha256. The room, table, mission, message, model and audio recipes retain their upstream data formats. The two inventory ledgers cover the 4,841 game data files. The release provides its own native component separately. The build utilities use local reference paths and a private working directory.

asset-inputs.tsv lists the private inputs needed by the writers and their expected fingerprints. It contains paths and digests. The license and notices in this directory apply to the supplied sources.
